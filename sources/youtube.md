# YouTube Research Playbook

## Objectives
Monitor high-velocity video tutorials, hands-on architectural breakdowns, and developer tool demonstrations. Identify rising interest through View-to-Age velocity.

## Metrics
- **View-to-Age Ratio ($V/A$):**
  $$V/A = \frac{\text{Total Views}}{\text{Hours Since Upload}}$$
  - A video with 20,000 views in 8 hours ($2,500\text{ views/hr}$) on a technical coding channel represents explosive early interest.
- **Tutorial Clustering:** Multiple independent channels publishing tutorials on the same framework within 48 hours indicates an emerging mainstream transition.

## Focus Topics
- Agent frameworks (LangGraph, CrewAI, AutoGen, MCP server implementation)
- Telegram Mini Apps & Bot development walkthroughs
- Next.js full-stack implementations, Supabase migrations, WebGPU graphics
