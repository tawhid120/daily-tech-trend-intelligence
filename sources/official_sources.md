# Official Sources Playbook

## Objectives
Official engineering blogs and documentation changelogs represent the highest tier of evidence (Tier 1, Reliability Score: 1.0). Always anchor breaking claims to primary documentation.

## Monitored Official Feeds
1. **AI Ecosystem:**
   - OpenAI News & Changelog (`https://openai.com/news/`)
   - Anthropic Research & Announcements (`https://www.anthropic.com/news`)
   - Google DeepMind Blog (`https://deepmind.google/discover/blog/`)
   - Meta AI Blog (`https://ai.meta.com/blog/`)
2. **Telegram Ecosystem:**
   - Telegram Bot API Changelog (`https://core.telegram.org/bots/api-changelog`)
   - Telegram Official Blog (`https://telegram.org/blog`)
3. **Web Ecosystem:**
   - Vercel Engineering Blog (`https://vercel.com/blog`)
   - Next.js Releases & Blog (`https://nextjs.org/blog`)
   - React Dev Blog (`https://react.dev/blog`)
   - Cloudflare Blog (`https://blog.cloudflare.com/`)
   - TypeScript DevBlog (`https://devblogs.microsoft.com/typescript/`)
