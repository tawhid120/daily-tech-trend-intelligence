# X / Twitter Research Playbook

## Objectives
X is the fastest real-time network for breaking AI announcements, model weights releases, benchmarks, and controversial technical debates among AI researchers, open-source maintainers, and founders.

## Monitored Signals
- **Breaking Releases:** Check posts from core maintainers, lab researchers (Anthropic, OpenAI, Meta, Google, Mistral), and developer advocates.
- **Viral Technical Threads:** Detailed breakdown threads explaining novel architectures, memory schemes, or optimization tricks.
- **Benchmark Critiques:** Independent developers reproducing or debunking company claims.

## Verification Rules
- Discard threads containing affiliate links or engagement-farming templates ("Bookmark this or cry later").
- Check if code repository or paper link is included. No link = **Unverified rumor**.
